# Overordnet
- Nettsiden skal ha en rekke funksjoner
	- Dashboard for lærer som kan opprette prøver og rette dem
		- Rettingen skal skje med ai-api og basere seg på en fasit og kjennetegn på måloppnåelse i faget (må legge inn kriterium og trene/instruere AI)
		- Elevene må få tilbakemelding pr oppgave umiddelbart etter de er ferdig. 
	- Elevportal hvor de logger inn (må ha noe anonymt, men med navn, GDPR problemer)
	- Selve prøvene hvor elevene skriver inn svar. Multiple choice, kort og langsvar. 

# Annet
- Firebase for auth og database
- Gemini API KEY
- Hostes på github pages, må ha deploy der
- url: prøve.haaland.de
- Dysleksi-knapp som endrer skrift
- Opplesing av oppgaver 



- Tekstfeltet som skal besvares i må ha forløpende lagring (ala google docs), slik at ingenting blir slettet hvis en tilfeldigvis trykker F5.
